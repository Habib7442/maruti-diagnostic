# Maruti Diagnostic Centre

An SEO-first, mobile-first healthcare marketing and doctor directory platform for **Maruti Diagnostic Centre**, located at SMC Point, Ghungoor, Silchar (opposite SMCH, behind Maruti Medical).

## Key Features

- **Daily Doctor Chamber**: Directory of 16 local medical specialists across 9 departments (Neurosurgery, Medicine, Gynaecology, ENT, Orthopaedics, Paediatrics, Dermatology, Surgery, Psychiatry).
- **Diagnostics & Pathology**: Overview of high-precision diagnostic tests (Pathology, Digital X-Ray, USG, ECG, Endoscopy) with turnaround times.
- **Local SEO Optimized**: Built for top Google rankings on consulting doctor queries (`"<doctor name> Silchar"`) with rich `Physician` and `MedicalClinic` JSON-LD schemas.
- **Direct Patient Action**: One-tap Call and WhatsApp booking triggers with persistent mobile bottom bar.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **UI & Styling**: React 19, Tailwind CSS v4, Lucide Icons
- **Fonts**: Fraunces & Hanken Grotesk via `next/font/google`
- **Language**: TypeScript (strict mode)

## Getting Started

First, install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
